# CipherCraft 🔐
A lightweight, interactive Caesar Cipher encoder and decoder built using vanilla JavaScript, HTML, and CSS. Ideal for learning the basics of classical cryptography and understanding how character shifting works in symmetric encryption.

---

## 🚀 Features

- 🔁 Encode or decode messages using Caesar Cipher logic
- 🎛️ Adjustable shift key (0-25)
- 🖥️ Simple, clean user interface
- 📋 One-click copy to clipboard
- ⚠️ Real-time error handling for empty input or invalid shift values
- ✅ No dependencies – pure HTML, CSS, and JS

## 🧠 How It Works

Caesar Cipher is a substitution cipher where each letter in the plaintext is shifted a fixed number of positions down or up the alphabet. Numbers are also shifted, while non-alphabetic characters remain unchanged.

- **Encode Mode**: Shifts characters forward by the key
- **Decode Mode**: Reverses the shift to reveal the original message
